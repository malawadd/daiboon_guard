# سياسة خصوصية دائبون

**تاريخ السريان: 9 نوفمبر 2026**

تشرح هذه السياسة البيانات التي يعالجها تطبيق دائبون عند تثبيته في مجتمع Reddit، وكيفية استخدامها وحفظها. يعمل التطبيق لمساعدة مشرفي المجتمع على تطبيق قواعد النشر والنقاش، ولا يقدم خدمة عامة خارج المجتمع الذي ثُبّت فيه.

## البيانات التي يعالجها التطبيق

قد يقرأ التطبيق عنوان المنشور ومتنَه والتعليقات ذات الصلة والسياق اللازم لتقييمها، إلى جانب معرّفات المحتوى وبيانات القرار الإشرافي. يفحص وجود صورة مرفقة بالمنشور آليًا. فحص محتوى الصورة اختياري، ونسبته الافتراضية صفر بالمئة.

عندما يحتاج المحتوى إلى تصنيف بالذكاء الاصطناعي، يرسل التطبيق النص ذي الصلة، مثل العنوان والمتن أو التعليق والتعليق الأب، إلى واجهة OpenAI API عبر النطاق `api.openai.com`. وإذا فعّل المشرف فحص الصور الاختياري، فقد تُرسل الصورة المحددة للفحص إلى النموذج أيضًا. يرسل التطبيق الطلب مع خيار `store: false`، لكنه لا يتحكم في جميع ممارسات الاحتفاظ لدى مزود الخدمة؛ لذلك يخضع ما يرسله لشروط OpenAI وضوابط بيانات واجهتها البرمجية.

يستخدم التطبيق مفتاح OpenAI المحفوظ كسرّ في إعدادات المطور. لا يكتب المفتاح أو ترويسة التفويض في سجلات التطبيق أو سجل القرارات.

## غرض الاستخدام

تُستخدم البيانات لتطبيق قواعد المجتمع: التحقق من صيغة المنشورات، وتقدير ارتباط المحتوى وجودته، وتقييم ملاءمة التعليقات. قد تؤدي النتيجة إلى السماح بالمحتوى أو إزالته أو إحالته للمراجعة، وفق وضع الإشراف الذي اختاره المشرفون. لا يستخدم مطورو دائبون بيانات Reddit لتدريب نموذج أو ضبطه.

قد يرسل التطبيق ردًا عامًا يشرح قرار الإزالة أو الإحالة للمراجعة، ويضيف ملاحظة إشرافية قصيرة. يستطيع المؤلف التواصل مع مشرفي المجتمع عبر Modmail للاعتراض أو طلب المراجعة.

## التخزين ومدة الاحتفاظ

يحتفظ سجل القرارات ببيانات وصفية مثل معرّف المحتوى، بصمة له، وقت القرار، مصدره، القاعدة والشرح المنقح، النتيجة وحالة الإشعار. لا يحتفظ سجل القرارات بنص المنشور أو التعليق كاملًا. الحد الأقصى للسجل 1,000 قرار، وتحذف سجلاته بعد مدة تصل إلى 14 يومًا.

تُحذف السجلات والإشعارات المعلّقة المرتبطة بحذف المؤلف للمحتوى. تُحفظ سجلات المحتوى الذي أزاله مشرف أو مسؤول Reddit لأغراض التتبع حتى انتهاء مدة الاحتفاظ. عند تعذر معرفة مصدر الحذف، يجري حذف السجل المرتبط احتياطًا. قد توجد بيانات تشغيلية مؤقتة أخرى في طوابير المعالجة أو ذاكرة التخزين المؤقت بمدد منفصلة.

التعليقات العامة وملاحظات الإزالة المنشورة على Reddit تتبع دورة حياة Reddit، ولا تُحذف تلقائيًا بانتهاء مدة سجل القرارات المحلي.

## الاطلاع والأمان

يمكن لمشرفي المجتمع المخوّلين الاطلاع على سجل القرارات من قائمتي **Daiboon decision** و **Daiboon activity**. يتحقق التطبيق من صلاحية المشرف عند كل طلب. تُحفظ بيانات السجل في مساحة Redis التي يوفرها Reddit للتطبيق، وتُرسل طلبات التصنيف عبر اتصال HTTPS إلى OpenAI.

## الاعتراض والتواصل

للاستفسار عن قرار إشرافي أو طلب مراجعة بيانات مرتبطة بمحتوى داخل المجتمع، راسل مشرفي المجتمع عبر Modmail في [مجتمع دائبون](https://www.reddit.com/message/compose?to=%2Fr%2Fdaiboon). أرفق رابط المحتوى ومعرّف القرار الظاهر في إشعار دائبون إن توفر. لا ترسل مفاتيح API أو معلومات سرية في Modmail.

قد تُحدّث هذه السياسة عند تغير طريقة عمل التطبيق أو متطلبات Reddit. تُنشر النسخة السارية عبر رابط سياسة الخصوصية في تفاصيل التطبيق.
